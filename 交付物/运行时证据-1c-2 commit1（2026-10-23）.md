### ③ GET 组图列表 → **返回 4 字段（`QuestionImageSummary`）**

```json
[
    { "id": 1, "order_index": 0, "file_ext": "png", "uploaded_at": "2026-10-23T15:51:43.389686Z" }
]
```

⭐ **①②③ 是最容易踩的坑**：**上传返 11 字段、列表返 4 字段**，两个不同类型。
前端若把上传返回值当 Summary 用 ⇒ TS 类型对不上；若把 Summary 当上传返回值用 ⇒ 少字段。

### ⑤ GET 详情 → **顺序 / meta / table_json 往返一致**

```
difficulty = B
kp_ids     = [1]
 block 0 text | text= '等高线稀疏处坡度______' | image_id= None | meta= None | table= None
 block 1 image | text= None | image_id= 1 | meta= {'image_width': 75} | table= None
 block 2 table | text= None | image_id= None | meta= None | table= {'rows': [['A', 'B'], ['1', '2']], 'header': True}
```

⭐ **顺序按数组顺序落 `order_index`（0 起）**；`meta.image_width` 原样存原样回；
`table_json` 的 `header`/`rows` 原样往返（**后端只当 dict 存，语义由前端定** ⇒ 契约由前端定死一份）。

### ⑥ PUT 不传 blocks ⇒ **保持不变**（不传 = 不动）

```
difficulty = A | blocks 数 = 3 | kp_ids = [1]
```

### ⑦ PUT `knowledge_point_ids: []` ⇒ **清空**

```
kp_ids = []
```

⇒ 三种语义**实测区分清楚**：`blocks` 不传=不动 / `knowledge_point_ids` 不传=不动 / 传 `[]`=清空。

### ⑧ DELETE 无 force ⇒ **409 + 三个计数**（前端必须读后端 message，**不许写死**）

```json
{"error_code":"CONFLICT","message":"题组含 0 道小题、1 张材料图、3 个材料块；确认删除请加 ?force=true","details":{"status_code":409},"request_id":"7a04a1d03724428ba6032f7a082955f4"}
HTTP=409
```

⭐ 计数在 **`message`** 里（`details` 被 `core/errors.py:121-124` 吞成 `{"status_code":409}`）
⇒ 前端只能读 `message` 解析数字 ⇒ **不许把计数写死在前端提示里**。
