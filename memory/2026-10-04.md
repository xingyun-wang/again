### D-74：取数对象必须与被描述对象同名 + 标"真值"必须并列 command + operand + "新尺寸/旧 mtime"内在矛盾 = 取证对象搞错（2026-10-04 立）

- **规则内容**（3 段合并）：
  1. **取数对象必须与被描述对象同名**：
     - 描述"某文件 mtime / 尺寸 / 权限"就 `stat <file>`（或 `ls -la <file>`）
     - 描述"某目录内容变动"才 `ls -d <dir>` / `ls -la <dir>/`（看目录本身）
     - 反例：写"文件 mtime = 21:53:43" 但命令是 `ls -la <dir>` → 取的是目录 mtime 不是文件 mtime
  2. **标"真值"必须并列 command + operand**（可回放；与 #45 同源加固）：
     - 形式：`真值（<command> <operand>）：<value>` —— 必须可回放
     - 反例："真值（`ls -la` + `stat`）：文件存在 + mtime 21:53:43" —— 没指定 operand，回放得到的是目录 mtime
  3. **「<新尺寸> / mtime <旧时刻>」内在矛盾 = 取证对象搞错**：
     - 二者只在"文件刚建、从未再改"时偶然相等（任何后续 commit 都会让 mtime 漂移）
     - 实证：12,732 B（改后尺寸）+ 21:53:43（改前目录 mtime）= 内在矛盾 ⇒ 取证对象搞错
