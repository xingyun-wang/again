### 教训（M1-B B.3 retro）

1. **FastAPI Form 依赖 `python-multipart`**：B.3.1 升级时缺这个包，build pytest 全炸（`RuntimeError: Form data requires "python-multipart"`）。**工程模板教训**：FastAPI 涉及 multipart 的项目必须在 pyproject.toml 显式列 python-multipart，不能依赖 fastapi 间接传递。
2. **nginx `client_max_body_size` 默认 1M**：35M PDF 上传直接 413。**工程模板教训**：docker compose 涉及文件上传的项目必须在 nginx.conf 显式设 client_max_body_size（建议 ≥ 100M，给教师用书 249M 留余量）。
3. **errors.py 自定义 ErrorResponse{message, error_code, request_id}**：包装 HTTPException 后响应里没有 `detail` 键（只有 message）。**教训**：单测断言用 `body.get("message", body.get("detail", ""))` 容错；或统一改用 message。
4. **runtime 容器不含 pytest/mypy/ruff**（slim by design）：本地容器内跑不了单测，要验证必须 rebuild 或 docker cp + pip install。**教训**：CI/dev 验证优先走 `docker compose build backend`（build 阶段会自动跑 ruff + mypy + pytest），快速验证可用 docker cp + 容器内 pip install。
5. **build 阶段 ruff 默认严格 I001（import 排序）+ SIM105（try-except-pass → contextlib.suppress）**：新写代码要预留这些自动修复。
