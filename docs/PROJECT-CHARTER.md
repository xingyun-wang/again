# Project Charter — 差异化作业工作台

> **项目宪法**：规则和状态分开。
> - **STATE.md** —— 当前进度、待办、决策点（频繁更新）
> - **CHARTER** —— 长期稳定的硬约束（轻易不改）

## 2. 产品边界（硬约束）

### ✅ 做透
- **教学闭环**：备课 → 出题 → 扫描 → 学情 → 反馈 → 备课下次
- **差异化作业**：4 档 + 老师审阅 + 手动调整档位
- **老师主导**：所有功能强化"老师决策"
- **纸质答题 + 扫描**：OMR 读卡机（主路径）+ 手机拍照 OCR（备用）
- **老师自建题库**：**沉淀式建模**（工作流里的顺手沉淀，非"录入动作"）
- **AI 备课助手**：简化版（重点/难点/授课建议），**不出作业**

### ❌ 不做（硬约束）
- 自适应学习推题 / 学生端自适应 / AI 生成课件
- AI 搜索课程实录 / 课程资源链接收藏
- 校本题库
- AI 直接给学生出作业 / AI 自动批改结果作为学生最终评价

---

## 3. 学科与章节

- **学科**：高中二年级 **地理**
- **MVP 章节**：**选择性必修 1 自然地理基础** 全 5 章
  - 第一章 地球的运动 / 第二章 地表形态的塑造 / 第三章 大气的运动
  - 第四章 水的运动 / 第五章 自然环境的整体性与差异性
- **班级规模**：单师多班，**单班 50 人**

## 6. 合规边界（**硬约束**，来自 2026-08-12 Phase 3 政策研究）

### ✅ 必须
- 家长授权机制（涉及 14 岁以下；MVP 一次性授权）
- 数据脱敏 / 本地化
- AI 生成内容声明
- 教师最终审阅流程
- 未成年人"钢铁模式"

### ❌ 禁止
- AI 直接给学生出作业
- AI 自动批改结果作为学生最终评价
- 用敏感数据训练模型
- 替代教师做育人主体

## 9. 协作原则（工作流约束）

1. **session 启动**：载曜先读 STATE.md + 最近 3 篇 memory + CHARTER（**≤ 3 分钟**）
2. **重大决策**：载曜出方案对比 + 风险评估，王星云拍板
3. **代码提交**：每个 W 子阶段独立 commit，commit message 含任务编号
4. **服务重启**：每次 session 启动 verify 5173 + 8000 都在（no nohup 持久化）
5. **改动 CHARTER**：必须主动告知王星云，并更新 STATE.md 的"最后更新"时间戳
