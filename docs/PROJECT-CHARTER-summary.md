## §1 一句话定位 ✅ 定稿

我们做的产品是一个**平台**——**老师主导的教学闭环操作系统**，深度嵌入教学环节。

v0.5 §0 定稿。e卷通 = 题库 + 报告工具；我们 = 教学闭环操作系统。

---

## §2 产品边界硬约束 ✅ 定稿

### ✅ 做透
- **教学闭环**：备课 → 出题 → 扫描 → 学情 → 反馈 → 备课下次
- **差异化作业**：4 档 + 老师审阅 + 手动调整档位
- **老师主导**：所有功能强化「老师决策」
- **纸质答题 + 扫描**：OMR 读卡机（主路径）；手机拍照 OCR 接口预留，**MVP 不做 UI**
- **老师自建题库**：**沉淀式建模**（工作流里的顺手沉淀，非「录入动作」）
- **AI 备课助手**：简化版（重点 / 难点 / 授课建议），**不出作业**

### ❌ 不做
- 自适应学习推题 / 学生端自适应 / AI 生成课件
- AI 搜索课程实录 / 课程资源链接收藏
- 校本题库
- AI 直接给学生出作业 / AI 自动批改结果作为学生最终评价

## §3 学科与用户边界 ✅ 定稿

### MVP 起点
- **教师**：王星云本人
- **学科**：**高中地理**（不锁年级）
- **班级**：单班 50 人
- **MVP 章节**：由星云每学期决定精录章节

### 平台最终覆盖
- 初中 / 高中 **全学段全学科**

### 学科 / 学段边界（硬约束）
- **学科之间独立**：每个学科老师有独立的题库 / 学情 / 备课空间，互相看不见
- **同学科跨学段也独立**：初中地理 / 高中地理完全分开
- **核心原则**：**题库属于教师个人资产，他人无法访问**
- **未来共享题库**：教师**主动选择上传**（共建题库愿景）

### 5 阶段用户扩展路径
| 阶段 | 范围 |
|---|---|
| MVP | 星云 + 自己班级（高中地理） |
| 全学段小范围 | 星云 + 1 初中地理老师（最小验证 = 2 人） |
| 跨学科小范围 | + 其他学科同事 |
| 单校多学科 | 单校全员老师 |
| 多校 | 多校老师 |

> **关于顺序**：全学段 in Phase 2（MVP 验证通过后立即开始）；**多学段 before 多校**（先内部矩阵验证，再规模复制）

## §5 题库与 AI 边界 ✅ 定稿

### 题库来源
| 来源 | 状态 |
|---|---|
| **老师自建题库** | ✅ MVP 核心（教师个人资产） |
| **外部题库**（菁优网 / 学科网 / 其他） | ✅ MVP 可用 |
| **AI 出题** | ⛔ **永久禁用**（v0.5 §3.3 强拍板） |
| **菁优网 API** | ⏳ 接口预留，未来重启 |

**老师角色 = 「内容策展人」**：决定每道题来源 + 本次作业的来源占比

### 反马太效应
- **D 档作业强制 20% 拔高**，从 C / B 档题池抽题
- 避免后进生自我放弃（v0.6 候选 = 仅从 C 档抽）

### AI 三类能力边界（v0.5 §5.5）
| 能力 | 性质 | MVP 状态 |
|---|---|---|
| **内容生成**（AI 出题） | AI 生成新内容 | ⛔ **永久禁用** |
| **综合分析**（AI 备课） | 综合学科知识库 + 学情 → 授课建议 | ✅ MVP 允许 |
| **数据提取**（AI 辅助录入） | LLM 预提取 PDF 结构化信息 | ✅ MVP 允许（人在回路） |

> **未来警惕**：AI 辅助录入如果演化为「AI 直接入库 + 老师只看」，会滑向内容生成。每次升级 AI 辅助录入前要重新评估

### 共建题库愿景（2026-08-30 拍板）
- **MVP**：不启用 `is_public`（题库严格个人）
- **阶段 2 启动**：教师主动选择上传（共享题库）

## §6 合规边界 ✅ 定稿

### ✅ 必须
- 家长授权机制（涉及 14 岁以下；MVP 一次性授权）
- 数据脱敏 / 本地化
- AI 生成内容声明
- 教师最终审阅流程
- 未成年人「钢铁模式」

### ❌ 禁止
- AI 直接给学生出作业
- AI 自动批改结果作为学生最终评价
- 用敏感数据训练模型
- 替代教师做育人主体
