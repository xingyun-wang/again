## §0 产品灵魂 ✅ 定稿（2026-09-14）

我们要做的产品是一个**平台**，**老师主导的教学闭环操作系统**，深度嵌入教学环节。

---

## §1 目标用户 + 5 阶段扩展 ✅ 定稿

- **MVP**：王星云（析木高中地理老师）+ 自己班级（单班 50 人）
- **5 阶段扩展**：MVP → 全学段小范围 → 跨学科小范围 → 单校多学科 → 多校
- **MVP 学科**：高中地理（不锁年级）
- **MVP 班级**：单班 50 人（后端可配）
- **MVP 章节**：星云每学期决定精录章节

**核心原则（§1.4）**：题库属于教师个人资产，他人无法访问；学科之间 / 同学科跨学段独立

---

## §2 核心场景（4 步闭环）✅ 定稿

**MVP 闭环 4 步**：
1. **备课**（教师上课前登录）→ AI 综合学科知识库 + 学情 → 授课建议
2. **出作业**（教师课后登录）→ 老师自建题库 + 外部题库 + 4 档差异化 + PDF 输出
3. **上传 + 评分**（学生上交作业）→ 教务处上传答题卡 + OMR 自动评分 + 主观题教师录分
4. **学情画像 + 再备课**（三维度画像）→ 教师根据反馈再备课 → 闭环形成

**使用节奏**：教师几乎每日登录（每步都涉及登录）

---

## §3 三大功能 ✅ 定稿

### §3.1 差异化作业（功能 1）
- **4 档位**：D 基础 / C 进阶 / B 挑战 / A 扩展（字母升序 = 难度升序）
- **动态调整**：K=5 / M=4（升档）+ N=3（降档）
- **题目来源**：老师自建题库（核心）+ 外部题库（菁优网 / 学科网）；**AI 出题 MVP 绝不碰**
- **输出**：PDF，每生一份
- **反马太**：D 档强制 20% 拔高（v0.6 候选 = 仅从 C 档抽）

### §3.2 学情反馈（功能 2）
- **三维度画像**：学生 + 班级 + 学科
- **数据来源**：选择题 OMR + 主观题教师录分 + 系统聚合
- **备课建议三层**：微观（每日）+ 中观（每周）+ 宏观（每周）
- **冷启动期**：5-10 课时；反馈标注置信度

### §3.3 AI 备课助手（功能 3）
- **输入**：学科知识库 + 学情画像
- **输出**（MVP 极简）：重点 / 难点 / 授课建议
- **学科知识库**：人教版高中地理全 5 册分阶段录（本学期精录 + 其他章节粗录）
- **LLM**：DeepSeek-V3（沿用 v0.5 §5.3.5）
- **AI 边界**：内容生成禁用 / 综合分析允许 / 数据提取允许

---

## §4 数据采集 ✅ 定稿

- **MVP 主路径**：OMR 读卡机 + 系统标准答题卡
- **备用**：手机拍照 OCR 接口预留（**MVP 不做 UI**）
- **最大 blocker**：§6.4 TWAIN 扫描仪实测验证（**MVP 启动前必过**）
- **数据存储**：本地为主 + 云端备份（阿里云 OSS，上传前脱敏）

---

## §5 合规边界 ✅ 定稿

- **家长授权**：MVP 一次性授权（涉及 14 岁以下）
- **数据脱敏**：本地 / 云端分级
- **未成年人「钢铁模式」**：小学强制 / 初中默认 / 高中默认（可关）
- **AI 生成内容声明**：UI 必标
- **教师最终审阅**：流程节点硬约束

---

## §6 MVP 范围 ✅ 定稿

- **平台最终覆盖**：初中 / 高中 全学段全学科
- **MVP 起点**：王星云 + 高中地理 + 单班 50 人
- **MVP 必须跑通 §2.2 4 步闭环**（教学闭环是灵魂）
- **MVP 试用启动条件**：4 步闭环跑通 + TWAIN 验证 + 本学期精录完成 + UI 走查
- **MVP 设备清单**：高速扫描仪（TWAIN）+ A4 打印机 + 教师电脑/iPad + 答题卡印刷品

---

## §7 技术选型 ✅ 定稿

- **前端**：React 18 + TypeScript + Vite + Ant Design 5
- **后端**：Python 3.11 + FastAPI + Celery（依赖保留；Phase 2 启用）
- **数据库**：PostgreSQL 15（开发 + 生产都用）
- **LLM**：DeepSeek-V3 + Provider 抽象层
- **部署**：Docker Compose 单机 MVP + 无状态 FastAPI
- **关键架构决策**：无状态 FastAPI / LLM Provider 抽象 / 数据模型预留学段字段 / 全程 PG / OSS 对象存储抽象
