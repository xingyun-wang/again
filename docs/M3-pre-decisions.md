## §5 硬约束（沿用现有纪律）

> 来自交接书 §5。

1. **定位三件套**：任何 git 结论前跑 `rev-parse --show-toplevel` + `--absolute-git-dir` + `HEAD`；toplevel 不是仓根 ⇒ 结论作废
2. **推送授权**：commit message 含 `[origin-push]`；**推 github 须星云单独批**
3. **测试闸门**：`cd backend && ruff check app tests && mypy app`；报绿必须带 **CI run 号 + commit**
4. **证据标准**：结论附 `文件:行号`；"改完了"不算证据；前端改动必须挂运行时证据
5. **不自行改产品决策**：batch 语义、识别码格式、分值规则均由星云拍板；有疑问先问
6. **编号唯一分配者**：新 D-XX 编号不要自取
