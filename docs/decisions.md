## 决策详情

### D-10：AI 辅助录入边界（重要）

**问题**：v0.5 §5.3.5 引入「AI 辅助录入」——LLM 预提取 PDF 里的标题 / 关键概念 / 重点 / 难点，星云审阅 + 编辑。

**三种 AI 能力的边界**：
- **内容生成**（AI 出题 = **禁**）：v0.4 / v0.5 §3.3 强拍板
- **综合分析**（AI 备课 = **允许**）：v0.5 §5.1-5.4 范围内
- **数据提取**（AI 辅助录入 = **允许，人在回路**）：v0.5 §5.3.5 新能力

**为什么"数据提取"不违反"内容生成禁令"**：
- AI 提取的是 PDF 里**已有**的内容（教参 / 教师手册）
- 星云审阅 + 编辑后入库
- 等价于"AI 辅助 OCR + 排版"，不是"AI 生成新题目"

**未来警惕**：AI 辅助录入如果演化为"AI 直接入库 + 老师只看"，会滑向内容生成。每次升级 AI 辅助录入前要重新评估。

### D-11：三维度画像 vs MVP 简化

**问题**：v0.5 §4.1 学情数据模型。我建议"MVP 仅学生 + 班级（学科画像 Phase 2+ 才有跨班级价值）"。用户拍板"三维度全要"。

**为什么用户拍板三维度全要**：
- 数据模型预留成本 O(1)
- 学科画像即使 MVP 阶段≈ 班级画像，Phase 2+ 无需重构
- 用户的整体哲学："**先建骨架，再填血肉**"

**未来警惕**：MVP 阶段学科画像可能没数据显示威（无跨班级数据），用户可能误以为没用。要在 §4 验证中明确"学科画像 MVP 阶段 ≈ 班级画像，Phase 2+ 显示威力"。
