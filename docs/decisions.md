## 决策详情

### D-10：AI 辅助录入边界（重要）

**问题**：v0.5 §5.3.5 引入「AI 辅助录入」——LLM 预提取 PDF 里的标题 / 关键概念 / 重点 / 难点，星云审阅 + 编辑。

**三种 AI 能力的边界**：
- **内容生成**（AI 出题 = **禁**）：v0.4 / v0.5 §3.3 强拍板
- **综合分析**（AI 备课 = **允许**）：v0.5 §5.1-5.4 范围内
- **数据提取**（AI 辅助录入 = **允许，人在回路**）：v0.5 §5.3.5 新能力

**为什么"数据提取"不违反"内容生成禁令"**：
- AI 提取的是 PDF 里**已有**的内容（教参 / 教师手册）
- 星云审阅 + 编辑后入库
- 等价于"AI 辅助 OCR + 排版"，不是"AI 生成新题目"

**未来警惕**：AI 辅助录入如果演化为"AI 直接入库 + 老师只看"，会滑向内容生成。每次升级 AI 辅助录入前要重新评估。

**例外条款**：
- 决策室可直接做的改动 = 机械性 / 确定性 / 不产生大 diff / 不需要迭代测试 的小改动
- 典型场景：1-3 行配置变更 / 决策记账（CHARTER / STATE.md / decisions.md / memory/ append 或 timestamp 更新）/ 文档校对
- 判断标准：完整 diff < 20 行 + 不需要跑代码测试
- 不属于例外：代码逻辑改动（即使 < 20 行）/ 测试改动 / 任何需要跑 pytest/mypy/ruff/build 的改动

**与 D-17 关系**：D-17（2026-09-15）写 §7.0 时只锁硬规则（写前后端/跑代码/debug 在工地），没明确"哪些可例外"。D-24 补例外条款，让 §7.0 既严格又有灵活性。

**未来警惕**：例外条款不是"放松 §7.0"，而是"明确边界"。每次决策室做例外改动，载曜主动判断是否符合 < 20 行 + 不跑代码测试——如果不符，立即转 subagent。

### D-25：§7.6 工程推进分阶段 + 每段验收（项目级硬规则）
